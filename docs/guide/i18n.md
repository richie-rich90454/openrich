# Internationalization

OpenRich ships with **11 built-in locales**. The editor auto-detects RTL/LTR from the locale.

## Usage

```tsx
<OpenRichEditor locale="ar" />   {/* RTL */}
<OpenRichEditor locale="en" />   {/* LTR */}
<OpenRichEditor locale="zh" />   {/* LTR */}
```

## Built-in Locales

| Code | Language   | Direction |
| ---- | ---------- | --------- |
| `en` | English    | LTR       |
| `zh` | Chinese    | LTR       |
| `es` | Spanish    | LTR       |
| `ar` | Arabic     | RTL       |
| `pt` | Portuguese | LTR       |
| `fr` | French     | LTR       |
| `ru` | Russian    | LTR       |
| `de` | German     | LTR       |
| `ja` | Japanese   | LTR       |
| `ko` | Korean     | LTR       |
| `hi` | Hindi      | LTR       |

## Custom Locale

```tsx
<OpenRichEditor
    locale={{
        dir: "rtl",
        messages: {
            "editor.placeholder": "اكتب هنا...",
            "editor.bold": "عريض",
        },
    }}
/>
```
